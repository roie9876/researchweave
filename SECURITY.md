# Security Policy & Autonomous Agent Guardrails

## Zero-Secret Repository Policy

- **No committed credentials:** Never commit Azure subscription keys, storage connection strings, OAuth client secrets, or personal tokens to this repository.
- **Managed Identity First:** All Azure deployments generated by `infra/main.bicep` and `infra/azuredeploy.json` use **User-Assigned Managed Identity** (`DefaultAzureCredential`) with least-privilege RBAC roles (`Storage Blob Data Contributor` and `Cognitive Services OpenAI User`) and `disableLocalAuth: true` on Azure AI Services.

## Autonomous Agent & Sandbox Safeguards

1. **Legality & Harm Guardrails:** Every research objective, clarifying response, and live steering instruction is screened by `check_guardrails()` before task creation. Unlawful, destructive, or bio-unsafe requests are rejected immediately.
2. **Isolated Sandbox Execution:** Computational scripts generated by specialist agents are statically inspected via Python AST (`validate_python_code_safety`) to block dangerous imports (`socket`, `subprocess`, `ctypes`, `shutil`, etc.) and executed in an isolated temporary directory (`python -I`) with stripped environment variables and strict timeouts.
3. **Epistemic Integrity:** Independent reviewer agents audit quantitative calculations and source hashes before marking claims as verified. Preclinical or theoretical hypotheses are never presented as proven clinical treatments or formal mathematical proofs without verification.

## Reporting a Vulnerability

Please report security issues privately via GitHub Security Advisories on the repository rather than opening a public issue containing exploit details.
